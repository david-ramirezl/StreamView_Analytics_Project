# Proyecto: StreamView Analytics

## Descripción del Proyecto
Este repositorio contiene la solución integral de Visualización de Datos para "StreamView Analytics".

## Estructura del Repositorio

- `data/`: Almacena los conjuntos de datos en sus distintos estados (crudos y procesados).
- `notebooks/`: Cuadernos interactivos (Jupyter) utilizados para el Análisis Exploratorio de Datos (EDA).
- `dashboard/`: Contiene el modelo de datos y el archivo interactivo de Power BI.
- `images/`: Recursos visuales estáticos, incluyendo la infografía del hallazgo estratégico.
- `src/`: Código fuente principal (scripts de Python) para procesamiento y limpieza.
- `docs/`: Documentación del proyecto, incluyendo informes técnicos y presentaciones.

## Entregables Principales
