# Directorio: data/

Este directorio centraliza todos los conjuntos de datos utilizados en el proyecto. Su separación previene la alteración accidental de los datos originales.

## Subdirectorios:
- `raw/`: Archivos originales tal como fueron entregados por la fuente.
- `processed/`: Archivos limpios, con variables desanidadas, tipos de datos corregidos y valores nulos tratados.
